## 7. Como executar no iPhone
**Opção A — Expo Go (rápida; sem Apple Sign-In nem Premium).** Em um computador:
```bash
git fetch origin claude/minuto91-v10-1-redesign
git checkout claude/minuto91-v10-1-redesign
cd app && npm install
# crie app/.env (não vai para o Git) com:
#   EXPO_PUBLIC_SUPABASE_URL=https://lqirpgqrnbsycuowwoie.supabase.co
#   EXPO_PUBLIC_SUPABASE_ANON_KEY=<chave anon do projeto minuto91-dev>   # Supabase > Project Settings > API
npx expo start --go --tunnel -c
```
Abra a câmera do iPhone no QR code (abre no Expo Go). `--tunnel` é obrigatório para o login com Google. O roteiro de teste do projeto é `docs/roteiro_teste_iphone.md`.

**Opção B — development build (inclui Apple e Premium; exige conta Apple paga).**
```bash
cd app && npx eas-cli@latest build --profile development --platform ios
# instale o build pelo link; depois:
npx expo start --dev-client -c
```
Entrar com a conta de teste do Supabase de desenvolvimento. Os dados são do banco `minuto91-dev`.
